# TypeWhisper CN Providers

A [TypeWhisper](https://typewhisper.com) plugin for Chinese and English dictation through China-hosted Xiaomi MiMo and ByteDance Seed-ASR 2.0. Supports both standard Seed billing and Volcengine Agent Plan subscriptions.

## Start here

- [Setup](docs/setup.md) — requirements, installation, API keys, and provider selection.
- [Development](docs/development.md) — local builds, implementation, and testing.
- [API reference](docs/API.md) — endpoints, recognition settings, and dictionary hotwords.

Requires macOS 14+ on Apple Silicon and TypeWhisper 1.5+.
